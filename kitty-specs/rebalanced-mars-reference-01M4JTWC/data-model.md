# Данные Rebalanced

Новое выключенное по умолчанию поле `expansions.rebalanced` соответствует persisted `rebalancedExpansion`. Для старого сохранения отсутствие означает false.

113 новых стабильных имён карт соответствуют активному манифесту референса. Пять комбинаций имеют отдельные имена, чтобы сохранение фиксировало вариант. Mars University и Meat Industry при совместном включении сохраняют существующие имена Better Mars.

Манифест задаёт тип карты, фабрику и совместимость. Условная замена содержит пару исходное имя → итоговое имя; клиент получает те же правила из экспорта. Для комбинации оригинал и обе одиночные версии удаляются только при наличии доступной итоговой версии.

Существующие DB rows, руки, deck order и сохранённые настройки старых партий не редактируются.
