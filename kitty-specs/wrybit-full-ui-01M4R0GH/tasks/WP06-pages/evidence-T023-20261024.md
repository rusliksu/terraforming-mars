# T023 — статистика и публичная read-only проекция

Дата: 2026-10-24. Пакет: WP06, подзадача T023. Ветка: `codex/wrybit-full-ui`.

## Контракт проекции

- Новый публичный маршрут: `GET /api/wrybit/stats`.
- Тип: `src/common/models/WrybitUiStats.ts`, `projectionVersion: 1`, source `elo`.
- Источник: уже публичный `assets/elo/elo-data.json`; база данных, админские endpoints, сессии и приватные поля не читаются.
- Проецируются только: id игры, дата, карта, поколения, число игроков, длительность, displayName, место, VP, корпорация, Elo before/after/delta.
- Сознательно отбрасываются: `_key`, `endId`, `server`, started/completed timestamps, внутренний `name`, любые неизвестные поля.

## UI

- `src/client/wrybit/pages/stats/StatsPage.vue`: Wrybit-страница с toolbar, загрузкой, ошибкой с retry, пустым состоянием.
- Вкладки: Overview, Games, Players, Corporations, Boards, Records.
- Фильтры: поиск по игроку/корпорации, фильтр карты, счётчик отфильтрованных игр.
- Overview: KPI, top players, top corporations, recent games.
- Games/Players/Corporations/Boards: таблицы; Records: highest VP, fastest game, largest Elo gain.
- Ссылка Statistics добавлена на StartScreen; при выключенном Wrybit старый `/elo/` остаётся fallback.

## Остаточные границы

- В публичной ELO истории нет карт/прелюдий/наград/milestone-деталей; эти source-вкладки не подменяются выдуманными данными и остаются вне текущей проекции.
- Статистика отражает публичный ELO-снимок, а не live-агрегацию базы; обновление файла ELO даёт новые данные без изменения UI.
- UI-18 в полной матрице остаётся открытой для сценариев, требующих этих отсутствующих деталей.
