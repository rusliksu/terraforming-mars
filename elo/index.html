TM ELO Ratings

Avg place = normalized finish score. Avg gen = average game generation. VP Margin = average gap to 2nd place if you win, otherwise gap to 1st.
How deltas work: each game is scored pairwise. Expected score is 1 / (1 + 10^((oppElo - myElo) / 400)), then delta = 32 / (players - 1) * (result - expected). In 3P each pair is half-size, and beating a much lower-rated player adds only a little.
