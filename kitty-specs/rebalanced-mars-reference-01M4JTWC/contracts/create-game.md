# Создание и сохранение партии

Существующие create-game маршруты принимают `expansions.rebalanced: boolean`, по умолчанию false. Persisted GameOptions содержит `rebalancedExpansion` и представление expansions. Отсутствующие поля старых сохранений означают false.

Ответы сервера, повторные настройки и экспорт/импорт шаблона сохраняют выбор. Новые endpoint, внешние запросы во время создания партии и миграция БД не требуются.

Список допустимых карт рассчитывается после совместимости дополнений. Условные замены применяются одинаково на сервере и клиенте через экспорт из манифестов. Ручные старые списки проходят фильтрацию. Проектные override старых партий без Rebalanced сохраняют существующее поведение.
