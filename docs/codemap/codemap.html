Три обязательных вопроса

Что вызывает модульserver.ts передаёт public capture в SentryProcessBoundary.ts; прямые owning calls находятся в process boundary, requestProcessor.ts и PlayerInput.ts.
Что он затрагиваетТолько формирование внешнего staging error event; HTTP response, gameplay, БД и public API не меняются.
Какие тесты покрываютSentryReporter.spec.ts, SentryProcessBoundary.spec.ts, requestProcessor.spec.ts, PlayerInput.spec.ts.

Статус evidence

Reporter и пять capture boundaries подтверждены source symbols и четырьмя профильными test files. Process использует SentryProcessBoundary.spec.ts, request — requestProcessor.spec.ts, три PlayerInput boundary — PlayerInput.spec.ts; финальный SDK envelope и privacy boundary проверяет SentryReporter.spec.ts.

Реальная доставка в Sentry не подтверждается этой картой: DSN, staging smoke и ingest остаются отдельным delivery gate.
