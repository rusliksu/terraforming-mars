# T021 — route matrix и evidence

Дата: 2026-10-24. Пакет: WP06, подзадача T021. Ветка: `codex/wrybit-full-ui`.

## Проверенная поверхность

- Wrybit включается через `experimental_layout=1`; выключение возвращает classic-страницу.
- Проверены StartScreen, Load, Games, Admin, Login, Help, а также Wrybit settings и help overlay.
- Источник данных — synthetic proof server на `127.0.0.1:8112/8113` с public fixtures; реальный сервер не использовался.
- Для Login использован mock `api/profile` с synthetic user; для Games — пустой `api/games`.

### Shell switch

На `/load`:

- `experimental_layout=0` → `wrybit=false`, `#load-game=true`, `.load-game-form=true`, overflow=false.
- `experimental_layout=1` → `wrybit=true`, `#load-game=true`, overflow=false.
- Console errors: 0 в обоих состояниях.

### Empty/error states

- Games empty: браузерный proof показывает «No games yet.»; unit test проверяет отсутствие таблицы.
- Games error: unit test подменяет fetch на `ok:false`; показывает «The game list could not be loaded.», кнопка retry делает второй запрос.
- Load: визуальная форма и submit-контракт сохранены из native-поведения; успешный rollback/reload на synthetic fixture не выполнялся, чтобы не менять серверное состояние.
