# T023 — статистика и публичная read-only проекция

Дата: 2026-10-24. Пакет: WP06, подзадача T023. Ветка: `codex/wrybit-full-ui`.

## Контракт проекции

- Публичный маршрут остаётся `GET /api/wrybit/stats`; тип `src/common/models/WrybitUiStats.ts`.
- Источник — уже публичный `assets/elo/elo-data.json`; БД, админские endpoints, сессии и приватные поля не читаются.
- Проецируются только id/date/map/generations/playerCount/duration/displayName/place/VP/corporation/ELO-поля.
- Отбрасываются `_key`, `endId`, `server`, timestamps, внутренний `name` и неизвестные поля.
- `src/client/wrybit/pages/stats/statsApi.ts` переводит проекцию в source-модель StatsGame; отсутствующие `details` не подменяются выдуманными картами/прелюдиями.

## UI

- Перенесён source `StatsPage.vue` и **все** source stats views/helpers: 44 файла в `src/client/wrybit/pages/stats/`.
- Вкладки: Overview, Games, Players, Corporations, Prelude cards, Project cards, Combinations, Milestones, Awards, Boards, Records — 11 source-вкладок.
- Перенесены source styles `stats_page.less` и source `card_list_source.less`; layout/filters/tables/showcase/chart-компоненты используют source-разметку.
- Публичная ELO-проекция даёт игры, игроков, корпорации и records; card/prelude/milestone/award/board детали отсутствуют и показываются пустыми состояниями, без фейковых данных.

## Остаточные границы

- Публичная ELO-проекция не содержит карт/прелюдий/milestone/award/board-деталей; соответствующие source-вкладки показывают пустые состояния, а не выдуманные данные. Полные data-backed сценарии — WP07.
- Статистика отражает публичный ELO-снимок, а не live-агрегацию БД; обновление файла ELO даёт новые данные без изменения UI.
