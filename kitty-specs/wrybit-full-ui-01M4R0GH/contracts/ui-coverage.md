# Матрица полного интерфейса

Все строки пока открыты. Статус «готово» требует реального сценария, исходной ссылки, пути адаптированного компонента и результата. Для групп дополнений разворачиваются отдельные строки по каждой доступной панели. Каждый исходный компонент классифицируется как перенесённый, общий повторно используемый, заменённый нашей реализацией с проверкой поведения либо относящийся к исключённому AI/серверу. Неатрибутированные пропуски запрещены.
