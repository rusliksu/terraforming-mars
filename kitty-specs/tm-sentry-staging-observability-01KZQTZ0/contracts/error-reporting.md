# Контракт исходящего события ошибок

## Публичная граница внутри сервера

```text
capture(error: unknown): void
```

Метод принимает только throwable. Он намеренно не принимает request, response, route context, player или game, чтобы приватные данные не могли быть добавлены вызывающим кодом.

## Предусловия отправки

- `SENTRY_DSN` задан непустым значением;
- `SENTRY_ENVIRONMENT` точно равно `staging`;
- build head является валидной hex Git revision;
- ошибка классифицирована вызывающей границей как неожиданная.

## Постусловия

- при выполнении предусловий формируется не более одного события на один вызов;
- событие соответствует allowlist из `data-model.md`;
- метод не бросает исключение, не меняет HTTP-ответ и не ожидает сетевую доставку;
- при невыполнении предусловий внешнего эффекта нет.

## Классификация

- исходные `AppError`, `InputError` и malformed JSON: ожидаемые, `capture` не вызывается;
- неожиданная undo-ошибка: `capture` вызывается до её преобразования в ожидаемый `InputError`;
- стандартный `Error`: исходные message/raw stack отбрасываются; сохраняются безопасная категория и нормализованные frame coordinates;
- иное значение: нейтральный тип и сообщение без сериализации исходного значения.

## Совместимость

Публичные HTTP-контракты Terraforming Mars, формат сохранённой игры и схема БД не меняются.
