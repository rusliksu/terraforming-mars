Dependencies: нет.

- [ ] T001 Сопоставить все активные фабрики с текущими оригиналами и зафиксировать независимый oracle по опубликованному коду. (WP01)
- [ ] T002 Добавить стабильные имена 113 замен и пяти комбинаций, модуль и выключенные по умолчанию настройки. (WP01)
- [ ] T003 Передать настройку через создание, модели, загрузку и повторные настройки, сохранив false для старых игр. (WP01)
- [ ] T004 Проверить все полные Record<Expansion> и относящиеся к ним старые fixtures; зафиксировать зависимости вне классов. (WP01)
