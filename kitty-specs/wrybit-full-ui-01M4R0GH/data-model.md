# Данные полного интерфейса

## Состояние режима

Единственный existing experimental_layout:boolean, default false. Сохранение — наш PreferencesManager. Включённый режим выбирает полный Wrybit; выключенный — обычные представления. Наш experimental_ui не получает defaults форка.

## Данные партии и ввода

PlayerViewModel, SpectatorModel, GameModel, PlayerInputModel и InputResponse остаются нашими authoritative контрактами. Wrybit-компонент получает текущий view, актуальный идентификатор/шаг ввода и callbacks нашего App. Не создаётся собственный state игры, AI или сохраняющий writer.

## Локальный контекст формы

Выбор карты, распределение оплаты и вложенный вариант принадлежат текущему запросу ввода. Переключение оболочки сохраняет их; изменение серверного шага очищает устаревший контекст. В payload не добавляются UI-настройки и декоративные данные.

## Read-only сведения UI

Source card, расширенные подписи и публичная статистика берутся из текущих моделей/канонических данных или из узкой собственной проекции. Публичная статистика содержит только whitelist завершённых сведений; private hands/drafts/raw saves исключены. Проверка доступа не ослабляется.

## Происхождение ресурсов

Manifest хранит URL, SHA источника, original path, destination, исходный hash и вид адаптации/повторного использования. Проверка полноты перечисляет весь исходный UI. Исходные стили и ресурсы изолированы от классического вида. Generated bundles не являются источником истины.
